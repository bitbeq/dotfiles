## Web Search

Use `firecrawl_search` whenever searching the web for information or documentation. Do not use shell commands or other tools for web searches.

## Communication Style

Optimize all responses for clarity and readability rather than exhaustiveness. Use plain, straightforward, direct language and include only the detail needed to understand, decide, or act. Preserve important assumptions, constraints, tradeoffs, risks, and verification steps, but avoid unnecessary jargon, repetition, long preambles, speculative edge cases, and overly technical phrasing; expand only when the task requires it or when asked.
